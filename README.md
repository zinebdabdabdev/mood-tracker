
# Mood Tracker 🌸

## About the Project
Mood Tracker is a simple Python application that allows users to record their daily moods and track their emotional history.

## Features
- Record daily moods.
- View mood history.
- Display mood statistics.
- Calculate mood percentages.
- Save data automatically using JSON.

## Technologies Used
- Python
- JSON
- Git
- GitHub

## Available Moods
- Happy
- Normal
- Sad
- Tired
- Angry

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
```
